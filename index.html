engine-and-brain-chess

LAN multiplayer chess app with Express, Socket.io, and Stockfish-assisted engine mode.

GitHub Pages cannot run the Node.js server or Socket.io multiplayer backend.

This project is designed to run locally on your LAN with a Node server.

Use:

npm install
node server.js

Then open the local URL shown by the server, such as http://localhost:3000 or your LAN IP.
